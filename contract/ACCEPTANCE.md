# 前端验收清单

以下清单用于 Agent 的自检和人工验收。只有实际执行并取得证据的项目才能标记为通过；不适用项目应说明原因。

## 数据准确性
- [ ] 数值列与表头同向右对齐，金额固定两位小数、千分位、等宽数字
- [ ] 零值、空值、无效值、负数、单位、币种、日期与时区表达正确
- [ ] 排序按原始数据类型执行，筛选与分页联动正确
- [ ] 图表轴、单位、图例、缺失值和对比基准正确

## 交互可靠性
- [ ] 深度链接、刷新、前进后退、404 正常
- [ ] 筛选和排序状态按需求恢复；空数据与筛选无结果分开显示
- [ ] 加载、成功、失败、重试和重复提交行为正确
- [ ] 破坏性操作的确认或撤销策略合理
- [ ] 键盘导航、焦点、可访问名称和错误提示可用

## 开发期组件定位
- [ ] 业务组件 ID 稳定、唯一、可按名称在源码中定位，不依赖文案与文件名
- [ ] 开关显示组件名称；点击真实名称标签可以复制对应 ID，且可选中文字手动复制；业务区域点击不被拦截

- [ ] 本地开发页面可选取一个真实业务组件并定位到 JSX/TSX 源文件与行号，可供 Agent 复现定位
- [ ] 生产构建中没有定位工具 UI、脚本或本机源码路径泄露

## 视觉与运行
- [ ] 目标屏幕尺寸下无无意的溢出、遮挡、列错位和弹窗越界
- [ ] 长文本、长数字、极端值、大数据量场景得到检查
- [ ] 类型检查、规范检查、构建及关键浏览器测试通过
- [ ] 对重要 UI 修改有实际截图或浏览器人工复核
- [ ] 报告未运行的测试、风险和偏离规范的理由

## 检查结果格式
报告必须使用中文，按“已验证 / 未验证 / 不适用 / 已知问题”分别陈述，禁止将缺失的测试视为通过。
